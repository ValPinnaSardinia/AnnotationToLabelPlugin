## Maintenance Status Notice (2026-05-23)

Please note that this plugin was originally developed around the legacy QGIS Text Annotation workflow available in older QGIS versions.

Since QGIS 3.40 and the ongoing QGIS 4 development cycle, the native QGIS annotation framework has evolved significantly and now includes expanded annotation layer support and more advanced built-in annotation tools.

For this reason, the plugin is currently maintained only as a lightweight legacy utility and no major feature expansion or full migration to the newer annotation framework is currently planned.

The plugin should still remain functional for its original intended workflow, and compatibility fixes may still be provided where reasonably possible.

However, if another developer or contributor is interested in continuing the development, modernisation, or long-term maintenance of the plugin, I would be very happy to discuss collaboration or transferring ownership of the project.

---

This plugin provides some useful tools to work with Text Annotations. 

A dedicated toolbar will provide some buttons to show/hide or remove the Text Annotations and a tool to convert the canvas map Text Annotations on print layout labels.
